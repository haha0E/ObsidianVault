# 静态网站托管

**一句话**：把 HTML/静态资源推到免费托管平台（GitHub Pages / Cloudflare Pages / EdgeOne Pages）就能拿到公网 HTTPS 域名；面向国内访问，腾讯 EdgeOne Pages 通常更快，且官方提供从 Cloudflare Pages 迁移的文档。

## 骨架问题（带着问题学）

- GitHub Pages、Cloudflare Pages、EdgeOne Pages 三者在免费额度、国内可达性、构建生态上各有什么差异？
- 静态托管和"全栈托管"（Functions/Workers 这类边缘函数）的边界在哪？什么需求一出现就必须升级？
- 从 Cloudflare Pages 迁到 EdgeOne Pages：`_redirects`/`_headers` 要改成 `edgeone.json`，还有哪些配置陷阱？
- 自定义域名、HTTPS 证书、CI 自动部署（连 GitHub 仓库）各家怎么配？
- 把 AI 生成的页面/文档挂到公网前，隐私与合规边界怎么判断（里面有没有不该公开的内容）？
